# راهنمای وارد کردن بکاپ کلینیک قدیمی به Animora (مخصوص کاربر مبتدی ویندوز)

این راهنما به زبان ساده و مرحله‌به‌مرحله توضیح می‌دهد که چطور فایل بکاپ نرم‌افزار قدیمی کلینیک
(`Clinic.bak`) را به اطلاعات قابل استفاده در **Animora** تبدیل کنید و آن را روی کلینیک موردنظر
وارد (Import) کنید. اگر با کامپیوتر زیاد حرفه‌ای نیستید هم نگران نباشید — هر قدم با جزئیات کامل
نوشته شده است.

> نسخهٔ خلاصهٔ فنی و جدول نگاشت فیلدها در فایل‌های [`README.md`](README.md) و [`FORMAT.md`](FORMAT.md)
> همین پوشه آمده است. این فایل فقط «نسخهٔ ساده و تصویری برای کاربر» است.

## کل کار در یک نگاه (فقط ۲ مرحله اصلی)

```
┌──────────────────────────┐        ┌───────────────────────────────┐
│  مرحله ۱: تبدیل          │        │  مرحله ۲: وارد کردن           │
│  فایل Clinic.bak   ───►  │  ───►  │  آپلود فایل خروجی در          │
│  به فایل خروجی           │        │  پنل ادمین Animora روی کلینیک │
│  clinic-import.animora.json │      │                               │
└──────────────────────────┘        └───────────────────────────────┘
```

- **مرحله ۱** را روی ویندوز و با یک «دابل-کلیک» انجام می‌دهید.
- **مرحله ۲** را داخل مرورگر و در پنل ادمین Animora انجام می‌دهید.

## پیش از شروع چه چیزهایی لازم دارید؟

1. **فایل بکاپ کلینیک**: فایلی با پسوند `.bak` (مثلاً `Clinic.bak`). این همان بکاپی است که از
   نرم‌افزار قدیمی کلینیک گرفته شده است. آن را جایی روی کامپیوتر کپی کنید که راحت پیدایش کنید،
   مثلاً داخل پوشهٔ `C:\Backups\`.
2. **پوشهٔ ابزار تبدیل**: پوشه‌ای به نام `clinic-bak-converter` (همین پوشه‌ای که این فایل داخل آن است).
   کل این پوشه را روی کامپیوتر ویندوزی کپی کنید.
3. **پایتون نسخهٔ ۳.۱۰ یا بالاتر**: یک نرم‌افزار رایگان که ابزار تبدیل با آن اجرا می‌شود.
   (در بخش بعدی نصبش را قدم‌به‌قدم توضیح داده‌ایم — اگر از قبل نصب است، آن بخش را رد کنید.)
4. **دسترسی به پنل ادمین Animora**: نام کاربری و رمز عبور یک حساب «اپراتور فروشنده (vendor operator)»
   که اجازهٔ ورود به پنل ادمین و بخش کلینیک‌ها را دارد.

> ⚠️ **نکتهٔ مهم دربارهٔ حریم خصوصی:** فایل بکاپ و فایل خروجی هر دو شامل **اطلاعات شخصی
> صاحبان حیوانات (نام، تلفن، کد ملی و ...)** هستند. این فایل‌ها را فقط روی کامپیوتر خودتان
> نگه دارید، برای کسی ایمیل/ارسال نکنید و **هرگز داخل گیت (Git) یا جای عمومی نگذارید.**

## مرحلهٔ صفر: نصب پایتون (فقط بار اول)

اگر مطمئن نیستید پایتون روی سیستم نصب است یا نه، این بخش را انجام دهید. اگر قبلاً نصب شده،
مستقیم بروید به **مرحلهٔ ۱**.

1. مرورگر را باز کنید و به این آدرس بروید: **https://www.python.org/downloads/**
2. روی دکمهٔ بزرگ زرد **Download Python 3.x.x** کلیک کنید تا فایل نصب دانلود شود.
3. فایل دانلودشده را اجرا کنید (دابل-کلیک روی فایلی مثل `python-3.12.x-amd64.exe`).
4. در پنجرهٔ نصب، **حتماً** تیک گزینهٔ زیر را در پایین پنجره بزنید:
   - ✅ **Add python.exe to PATH**
   (این تیک خیلی مهم است؛ اگر آن را نزنید ابزار پیدا نمی‌شود.)
5. روی **Install Now** کلیک کنید و منتظر بمانید تا نصب تمام شود، سپس **Close** را بزنید.

برای اطمینان از نصب درست (اختیاری):
- کلید `Windows` را فشار دهید، تایپ کنید `cmd` و **Command Prompt** را باز کنید.
- دستور زیر را تایپ کنید و `Enter` بزنید:
  ```cmd
  py --version
  ```
- اگر چیزی شبیه `Python 3.12.3` نشان داد، یعنی نصب درست انجام شده است. ✅

## مرحلهٔ ۱: تبدیل فایل `Clinic.bak` (روی ویندوز، با دابل-کلیک)

این ابزار **هیچ نیازی به نصب SQL Server یا دیتابیس ندارد** و همه‌چیز را خودش انجام می‌دهد.

### قدم ۱-۱: اجرای ابزار
1. وارد پوشهٔ `clinic-bak-converter` شوید.
2. روی فایل **`run-converter.cmd`** دابل-کلیک کنید.
   - یک پنجرهٔ سیاه‌رنگ (Command Prompt) باز می‌شود. این طبیعی است، نترسید. 🙂

> اگر ویندوز هشدار امنیتی «Windows protected your PC» نشان داد، روی **More info**
> و بعد **Run anyway** کلیک کنید. (این فایل فقط یک اسکریپت ساده برای اجرای ابزار است.)

### قدم ۱-۲: وارد کردن مسیر فایل بکاپ
پنجره از شما این را می‌پرسد:

```
Enter the full path to the Clinic.bak file:
```

- مسیر کامل فایل بکاپ را تایپ یا **پیست (Paste)** کنید. مثلاً:
  ```
  C:\Backups\Clinic.bak
  ```
- سپس `Enter` بزنید.

> 💡 **ساده‌ترین راه برای گرفتن مسیر فایل:** در File Explorer روی فایل `Clinic.bak`
> کلیک راست کنید و گزینهٔ **Copy as path** (کپی به‌عنوان مسیر) را بزنید، بعد داخل پنجرهٔ
> سیاه کلیک راست کنید تا پیست شود. (ابزار علامت‌های نقل‌قول `"` را خودش حذف می‌کند، نگران نباشید.)

### قدم ۱-۳: انتخاب محل ذخیرهٔ فایل خروجی
بعد این سؤال می‌آید:

```
Enter output bundle path [default: clinic-import.animora.json]:
```

- اگر فقط `Enter` بزنید، فایل خروجی با نام پیش‌فرض **`clinic-import.animora.json`**
  داخل همین پوشهٔ ابزار ساخته می‌شود. (برای اکثر کاربران همین کافی است.)
- یا می‌توانید یک مسیر دلخواه بدهید، مثلاً:
  ```
  C:\Out\clinic-import.animora.json
  ```

### قدم ۱-۴: صبر کنید تا تبدیل تمام شود
ابزار چند ثانیه کار می‌کند و در پایان یک **خلاصه** نشان می‌دهد؛ چیزی شبیه این:

```
  owners:        547
  pets:          694
  visits:        3
  vaccinations:  1006
  antiparasites: 1544
  invoices:      6399
  stockReceipts: 159
  services:      33
  products:      555
  ...
  warnings:      5

Wrote clinic-import.animora.json (...KiB). It contains personal data -
upload it in the admin panel and do not commit it.
```

و در انتها این پیام را می‌بینید:

```
[OK] Bundle written to: clinic-import.animora.json
     Upload it in the Animora admin panel on the clinic's Import page.
```

🎉 **تبریک!** مرحلهٔ تبدیل تمام شد. حالا یک فایل `clinic-import.animora.json` دارید.

> **عددها یعنی چه؟** هر خط نشان می‌دهد چند مورد از هر نوع اطلاعات استخراج شده است:
> `owners` = صاحبان حیوان، `pets` = حیوانات، `visits` = ویزیت‌ها، `vaccinations` = واکسن‌ها،
> `invoices` = فاکتورها و ... . پنجره را ببندید (یا کلید `Enter` را بزنید).

#### دربارهٔ «warnings» (هشدارها) نگران نباشید
هشدارها به معنی خطا **نیستند**. ابزار فقط به شما می‌گوید بعضی موارد جزئی را نتوانسته کامل منتقل
کند (مثلاً عکس لوگوی کلینیک یا چند ردیف حذف‌شدهٔ قدیمی). بقیهٔ اطلاعات سالم و کامل منتقل شده‌اند.
تا وقتی در انتها پیام **`[OK]`** می‌بینید، همه‌چیز درست است.

#### اگر به‌جای `[OK]` خطا دیدید
| پیام خطا | معنی و راه‌حل |
|---|---|
| `Python 3 was not found on this computer` | پایتون نصب نیست یا تیک **Add to PATH** زده نشده. به **مرحلهٔ صفر** برگردید. |
| `Input file not found` | مسیر فایل `.bak` اشتباه است. مسیر را دوباره با **Copy as path** بگیرید. |
| `cannot read backup` | فایل بکاپ خراب یا ناقص است. یک نسخهٔ سالم‌تر از بکاپ تهیه کنید. |
| `generated bundle failed validation` | اطلاعات منبع مشکل ساختاری دارد؛ متن خطا را برای تیم فنی Animora بفرستید. |

## مرحلهٔ ۲: وارد کردن فایل به کلینیک (در پنل ادمین Animora)

حالا فایل `clinic-import.animora.json` را در پنل ادمین روی کلینیک موردنظر آپلود می‌کنیم.
این مرحله **دو بخش** دارد: اول **بررسی/پیش‌نمایش** و بعد **ورود نهایی**.

### قدم ۲-۱: ورود به پنل ادمین
1. مرورگر را باز کنید و وارد پنل ادمین **Animora** شوید.
2. با حساب **اپراتور فروشنده (vendor operator)** خودتان **Sign in** کنید.

### قدم ۲-۲: رفتن به صفحهٔ Import کلینیک
1. از منو وارد بخش **کلینیک‌ها (Tenants)** شوید.
2. **کلینیک مقصد** را از لیست پیدا و انتخاب کنید.
3. روی دکمهٔ **«بارگذاری بستهٔ اطلاعات قدیم» (Import Legacy Bundle)** کلیک کنید.
   - آدرس این صفحه چیزی شبیه این است: `/admin/tenants/{شناسهٔ‌کلینیک}/import`

> ⚠️ **خیلی مهم:** دقت کنید که **کلینیک درست** را انتخاب کرده باشید. اطلاعات روی همان کلینیکی
> وارد می‌شود که اینجا انتخاب کرده‌اید.

### قدم ۲-۳: پیش‌نمایش و اعتبارسنجی (بدون تغییر در اطلاعات)
1. روی دکمهٔ انتخاب فایل بزنید و فایل **`clinic-import.animora.json`** را انتخاب کنید.
2. روی **«اعتبارسنجی بسته» (Validate)** کلیک کنید.
3. حالا تعداد موارد را می‌بینید: چند صاحب حیوان، چند حیوان، چند ویزیت، چند واکسن، چند فاکتور و ... .
   این عددها باید **با همان خلاصه‌ای که در مرحلهٔ ۱ دیدید بخوانند.**
4. اگر هشداری هم بود مرور کنید؛ این مرحله **هیچ تغییری در اطلاعات کلینیک نمی‌دهد** و فقط
   «تمرین» یا پیش‌نمایش است.

> اگر تعدادها منطقی به نظر می‌رسند، به قدم بعد بروید. اگر عددها عجیب‌اند (مثلاً همه صفر)،
> احتمالاً فایل اشتباهی انتخاب شده — دوباره بررسی کنید.

### قدم ۲-۴: ورود نهایی اطلاعات به کلینیک
1. دوباره همان فایل `clinic-import.animora.json` را انتخاب کنید.
2. تیک **تأیید (confirmation box)** را بزنید.
3. روی **«اجرای ورود اطلاعات به کلینیک» (Import)** کلیک کنید.
4. سرور اطلاعات را داخل یک تراکنش امن و مخصوص همان کلینیک وارد می‌کند، همه ردیف‌ها را به
   شناسهٔ کلینیک (TenantId) می‌چسباند و یک رکورد ممیزی (audit) از عملیات ثبت می‌کند.

🎉 **تمام شد!** اطلاعات کلینیک قدیمی حالا داخل Animora است و از طریق **همگام‌سازی (Sync)**
معمولی روی دستگاه‌های دسکتاپ آن کلینیک در دسترس قرار می‌گیرد.

## نکتهٔ طلایی: وارد کردن دوباره خطرناک نیست (Idempotent)

اگر لازم شد همان فایل را **دوباره** وارد کنید (مثلاً شک داشتید کامل انجام شده)، نگران نباشید:
ابزار برای هر رکورد یک «شناسهٔ پایدار» می‌سازد، پس وارد کردن دوبارهٔ همان فایل روی همان کلینیک،
رکوردها را **به‌روزرسانی/حفظ می‌کند و رکورد تکراری نمی‌سازد.** اطلاعات دوتا نمی‌شود.

## روش جایگزین برای کاربران حرفه‌ای (خط فرمان)

اگر ترجیح می‌دهید به‌جای دابل-کلیک از خط فرمان استفاده کنید، می‌توانید مستقیم اجرا کنید:

```cmd
run-converter.cmd "C:\Backups\Clinic.bak" "C:\Out\clinic-import.animora.json"
```

یا بدون لانچر، مستقیم با پایتون:

```cmd
py -m converter --bak "C:\Backups\Clinic.bak" --out "clinic-import.animora.json" --verbose
```

| گزینه | توضیح |
|---|---|
| `--bak PATH` | مسیر فایل ورودی `Clinic.bak` (الزامی) |
| `--out PATH` | مسیر فایل خروجی (پیش‌فرض: `clinic-import.animora.json`) |
| `--verbose` | نمایش جزئیات کامل تعداد ردیف‌ها و هشدارها |
| `--raw` | قرار دادن همهٔ ردیف‌های خام در فایل خروجی (فایل بزرگ‌تر، فقط برای عیب‌یابی) |

## سؤالات پرتکرار (FAQ)

**❓ آیا باید SQL Server یا دیتابیس نصب کنم؟**
نه. ابزار مستقل است و فقط به پایتون نیاز دارد.

**❓ فایل خروجی را کجا باید نگه دارم؟**
فقط روی کامپیوتر خودتان، تا وقتی که آن را در پنل ادمین آپلود کنید. بعد از ورود موفق،
می‌توانید فایل بکاپ و فایل خروجی را در جای امن آرشیو کنید یا پاک کنید. **جایی عمومی نگذارید.**

**❓ اطلاعات «پانسیون (Boarding)» چرا منتقل نشد؟**
نرم‌افزار قدیمی جدولی برای پانسیون نداشته، پس این بخش در Animora خالی می‌ماند. این طبیعی است.

**❓ تاریخ‌ها درست منتقل می‌شوند؟**
بله. تاریخ‌های شمسی (جلالی) به‌صورت خودکار و دقیق به تاریخ معتبر تبدیل می‌شوند و تقویم جلالی
کلینیک جابه‌جا نمی‌شود.

**❓ اگر وسط کار قطع شد چه کنم؟**
فقط دوباره از اول همان مرحله را تکرار کنید. چون عملیات امن و قابل‌تکرار است، مشکلی پیش نمی‌آید.

Animora بفرستید تا سریع راهنمایی کنید.

# بخش A — پنج خواستهٔ صریح کاربر (اولویت بالا، اول این‌ها)

## A-1 — ثبت بیمار جدید از داخل ثبت نوبت (باز کردن منوی اصلی، بستن خودکار، انتخاب خودکار، حفظ تنظیمات)
**محل:** BookingVM:771–788 (`BeginAddPatient`, `SelectCreatedPatientAsync`)

**واقعیت کد (مهم — این احتمالاً از قبل پیاده شده است؛ فقط «راستی‌آزمایی و تکمیل» کن، از نو نساز):**
```csharp
[RelayCommand]
private void BeginAddPatient()
{
    var wizard = new AddPatientWizardViewModel(
        _patients, _dialogs, result => _ = SelectCreatedPatientAsync(result), closeModalOnly: true);
    _dialogs.ShowModal(wizard, maxWidth: 760);
}
```
یعنی ویزاردِ اصلیِ ثبت بیمار باز می‌شود، `closeModalOnly:true` فقط لایهٔ مودال را می‌بندد (پس انتخاب‌های فرم نوبت: نوع/پزشک/تاریخ/ساعت/یادداشت/سوییچ‌های SMS حفظ می‌شوند)، و `SelectCreatedPatientAsync` بیمار ساخته‌شده را خودکار انتخاب می‌کند.

**کار لازم (فقط راستی‌آزمایی/تکمیل، نه بازنویسی):**
1. مطمئن شو `AddPatientWizardViewModel` همان منوی **اصلیِ** ثبت بیمار است (نه یک فرم سادهٔ موازی). اگر فرم سادهٔ جداگانه‌ای هم در مسیر هست، آن را با همین ویزارد اصلی یکی کن.
2. بعد از ثبت، مودال خودکار بسته شود و بیمار جدید در فیلد بیمارِ فرم نوبت انتخاب شده باشد (تأیید `ApplySelectedPatient`).
3. تأیید کن هیچ‌کدام از انتخاب‌های قبلی فرم نوبت از بین نمی‌رود.
4. اگر همه‌چیز درست است، فقط این مورد را «تأیید شد» علامت بزن و کد اضافه نساز.

**معیار پذیرش:** از داخل ثبت نوبت، «بیمار جدید» منوی اصلی را باز کند؛ پس از ثبت، خودکار بسته شود، بیمار انتخاب شود و تنظیمات فرم نوبت دست‌نخورده بماند.
